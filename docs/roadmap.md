# 路线图事实源

## Phase 1：免费静态题库

Phase 1 只做 free 内容和前端静态体验，目标是把合同、内容、架构边界和 CI 门禁先固定下来。

当前允许范围：

- 共享 Question 和 Scorecard 合同。
- 免费公开题库内容。
- 静态前端刷题页面。
- 浏览器本地练习记录。
- 内容校验、架构守卫、类型检查、测试、构建和格式检查。
- GitHub Issue、PR 和 CI 流程。

当前不允许范围：

- 后端服务。
- 登录或账号系统。
- 支付、订阅、会员或 VIP 实现。
- 私有题库或付费答案进入 git 可见文件。
- 在 app 层重新定义核心模型或硬编码内容分类数组。

## Phase 1 完成标准

- 公开仓库只包含 free-only 内容。
- `pnpm run ci` 在本地和 GitHub Actions 通过。
- 后续功能通过 Issue 驱动，并引用 `docs/product.md`、本文件和必要的代码合同文档。

## 未来阶段

未来可以评估后端、账号、支付、会员、VIP 内容和更完整的商业化能力。它们目前只是规划方向，不属于 Phase 1 代码范围。
